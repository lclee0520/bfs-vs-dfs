## 📌 개요

**"가중치 없는 그래프에서 출발 정점부터 목표 정점까지 경로 찾기"** 라는 같은 문제를 BFS(너비 우선 탐색)와 DFS(깊이 우선 탐색)로 풀고, 두 알고리즘의 내부 동작을 같은 그래프 위에서 단계별로 나란히 보여 주는 웹앱입니다.

둘 다 경로는 찾지만 **BFS만 최단 경로를 보장**합니다. 다음에 볼 정점을 큐(FIFO)에서 꺼내느냐 스택(LIFO, 재귀)에서 꺼내느냐 하는 차이 하나가 탐색 모양 전체를 바꾸는 과정을 확인할 수 있습니다.

## 🗺️ 예제 그래프

정점 8개 무방향 그래프입니다. 출발은 1, 목표는 8이고 인접 정점은 번호 오름차순으로 방문합니다.

```
        4
        |
        2 ─── 5 ─── 6
       /              \
 출발 1                7
       \              /
        3 ────────── 8 목표

간선: 1-2, 1-3, 2-4, 2-5, 5-6, 6-7, 7-8, 3-8
```

| 정점 | 인접 리스트 | 비고 |
|---|---|---|
| 1 | 2, 3 | 출발 |
| 2 | 1, 4, 5 | |
| 3 | 1, 8 | 짧은 길 |
| 4 | 2 | 막다른 길 |
| 5 | 2, 6 | |
| 6 | 5, 7 | |
| 7 | 6, 8 | |
| 8 | 3, 7 | 목표 |

이 그래프에서는 두 장면이 나옵니다.
- DFS가 막다른 길 4에 들어갔다가 되돌아오는 장면 (backtracking)
- DFS가 긴 길(1→2→5→6→7→8)로 돌아가는 사이 BFS는 짧은 길(1→3→8)을 찾는 장면

## ⚙️ 핵심 의사코드

```
BFS(G, s, t)                              DFS(G, u, t)
    visited[s] = true                         visited[u] = true
    Q.enqueue(s)                              if u == t: return true
    while Q not empty                         for v in adj[u]
        u = Q.dequeue()                           if not visited[v]
        if u == t: return path(parent, t)             parent[v] = u
        for v in adj[u]                               if DFS(G, v, t): return true
            if not visited[v]                 return false
                visited[v] = true
                parent[v] = u
                Q.enqueue(v)
```

## 📊 실행 결과 비교

| 항목 | BFS | DFS |
|---|---|---|
| 찾은 경로 | 1 → 3 → 8 | 1 → 2 → 5 → 6 → 7 → 8 |
| 경로 길이 | **2** (최단) | **5** |
| 처리한 정점 | 6개 (큐에서 꺼낸 정점) | 7개 (재귀 호출된 정점) |
| 되돌아감 | 없음 | 1회 (4 → 2) |
| 시간 복잡도 | O(V + E) | O(V + E) |
| 공간 복잡도 | O(V), 큐 | O(V), 재귀 스택 |
| 최단 경로 보장 | O (무가중치) | X |

## ✨ 주요 기능

- **나란히 비교**: 같은 단계 번호에서 BFS와 DFS 상태를 좌우로 동시에 표시
- **단계 이동**: 처음 / 이전 / 다음 / 끝 버튼, 슬라이더, 자동재생, 키보드 ← →
- **단계별 설명**: 매 단계마다 "한 일"과 "이유"를 함께 표시
- **자료구조 표시**: BFS는 큐(앞 → 뒤), DFS는 재귀 스택(바닥 → 꼭대기)
- **의사코드 하이라이트**: 현재 단계에서 실행된 줄을 강조
- **시각 표현**: BFS는 거리별 색이 번지는 모습, DFS는 방문 순서(#k)와 되돌아가는 화살표
- **실제 실행 기반**: 단계 데이터를 손으로 적지 않고 BFS/DFS 코드를 실행하며 기록
